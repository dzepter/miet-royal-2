# Maschinenschemata (Assets)

Ablage für echte Schema-Grafiken der Maschinentypen (Phase-7-Order §30,
Asset-Schnittstelle des Schadensschemas). Die aktuellen Schemata sind als
Inline-SVG im Bundle enthalten und damit offline immer verfügbar; Dateien in
diesem Ordner (`<productSlug>-<front|back|left|right>.svg`) werden vom Service
Worker (`stale-while-revalidate`) für den Offline-Betrieb gecacht.
